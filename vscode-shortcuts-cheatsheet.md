# My VS Code Shortcuts (macOS)
*Personal cheat sheet — reflects keybindings.json as of Aug 2026*

## Navigation & Search

| Shortcut | Action |
|---|---|
| `Cmd+P` | Quick Open (go to file) |
| `Cmd+R` | Go to Symbol in file |
| `Cmd+G` | Go to Line |
| `Cmd+Shift+P` | Command Palette |

## Selection & Multi-cursor

| Shortcut | Action |
|---|---|
| `Cmd+L` | Select/expand current line |
| `Cmd+Shift+L` | Select all occurrences |
| `Cmd+D` | Add cursor to next matching occurrence |

## Line Editing

| Shortcut | Action |
|---|---|
| `Cmd+Shift+D` | Duplicate current line down |
| `Opt+Up` / `Opt+Down` | Move line up/down |
| `Cmd+/` | Toggle line comment |

## Tab & Editor Group Navigation

| Shortcut | Action |
|---|---|---| 
| `Cmd+1-9` | jump to editor group 1-9 |

| `Cmd+Left` | jump to prev editor in editor group |
| `Cmd+Right` | jump to next editor in editor group |

| `Cmd+Shift+Left` | move current editor to left editor group |
| `Cmd+Shift+Right` | move current editor to right editor group |

| `Cmd+Shift+1` | Move active editor **group** left (reorders panes) |
| `Cmd+Shift+2` | Move active editor **group** right (reorders panes) |
| `Cmd+Shift+3` | Move active editor **group** up (reorders panes) |
| `Cmd+Shift+4` | Move active editor **group** down (reorders panes) | 

## Code Runner Extension

| Shortcut | Action |
|---|---|
| `Cmd+Enter` | Run code |
| `Cmd+Shift+Enter` | Run code in integrated terminal |

## Everything else

| Shortcut | Action |
|---|---|
| `Cmd+B` | Toggle sidebar |
| `Cmd+\` | Split editor |
| `` Ctrl+` `` | Toggle terminal |
| `Cmd+Shift+O` | Remove all unused imports from focused file |
| `Cmd+K Z` | Zen mode (distraction-free) |
| `Opt+Cmd+O` | Toggle overtype/insert mode |
