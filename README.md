### [Gakuji](https://github.com/13kanaoka/Gakuji) — Kanji Study App
`Flutter` `Firebase` `SQLite`

Cross-platform app for mastering Japanese kanji on iOS, Android, and Web, with account-based cloud sync via Google Sign-In and Cloud Firestore. Uses adaptive spaced-repetition scheduling (FSRS algorithm) and on-device handwriting recognition via Google ML Kit, backed by a custom pipeline parsing the JMdict dictionary into a bundled SQLite database.

**Status →** In development

### [CSUN Chat App](https://github.com/13kanaoka/csun-chat-app) — Student-Facing Real-Time Messaging App ([Live Demo](https://13kanaoka.github.io/csun-chat-app/))
`MongoDB` `Express` `React` `Node.js` `WebSockets`

Built with a 4-person Agile team using Jira and Git as part of COMP 380 (Intro to Software Engineering). Includes real-time messaging, user authentication, profile management, and photo sharing, backed by an Express/Node.js API and MongoDB persistence.

**Status →** Completed

### [JSA Website](https://github.com/13kanaoka/jsa-website) — Club Membership & Info Site ([Live Demo](https://csunjsa.vercel.app/))
`React` `JavaScript` `HTML` `CSS` `MongoDB`

Site for CSUN's Japanese Student Association where members can sign up, apply for board positions, learn about the club, and meet the current board. Supports English/Japanese language toggling, backed by a MongoDB database for user info.

**Status →** Completed
